# Лёха AI — ИИ-агент как участник конкурса прогнозов

**Дата:** 2026-06-01
**Статус:** Approved

## Цель

Добавить пятого участника конкурса — ИИ-агента "Лёха AI". Агент автономно делает прогнозы на все матчи в игровые дни в рамках окна 9:00–18:00 МСК, участвует в рейтинге на общих основаниях.

## Архитектура

```
Vercel Cron (12:00 UTC / 15:00 МСК, ежедневно)
       │
       ▼
api/cron_ai_predict.py
   ├─ Проверяет: есть ли сегодня открытый игровой день?
   ├─ Если нет → ранний выход (Claude не вызывается, стоимость $0)
   ├─ Проверяет: уже есть прогнозы Лёхи AI? → пропускает (идемпотентность)
   ├─ Собирает контекст из Supabase:
   │    ├─ Матчи сегодня (match_id, team_home, team_away)
   │    └─ Текущая статистика по группам (очки, голы, форма команд)
   ├─ Вызывает Claude API → получает JSON с прогнозами
   ├─ При ошибке → отправляет алерт администратору в Telegram
   └─ Записывает прогнозы через upsert_prediction() → Supabase
```

Никаких новых инфраструктурных компонентов. Один новый файл + расширение существующих.

## Изменения в БД

### Миграция

```sql
-- Убираем NOT NULL, чтобы у AI-участника не было telegram_id
ALTER TABLE participants ALTER COLUMN telegram_id DROP NOT NULL;

-- Создаём участника (выполнить один раз)
INSERT INTO participants (telegram_id, name) VALUES (NULL, 'Лёха AI');
```

PostgreSQL допускает несколько NULL в UNIQUE-колонке, существующие участники не затрагиваются. View `v_scores` и leaderboard работают без изменений.

## Компоненты

### `api/cron_ai_predict.py` (новый файл)

Vercel serverless handler. Логика:

1. Проверить авторизацию (`CRON_SECRET`)
2. Получить сегодняшний игровой день со статусом `open`
3. Получить матчи игрового дня
4. Проверить, нет ли уже прогнозов Лёхи AI на эти матчи
5. Собрать турнирный контекст (функции из `bot/db.py`)
6. Вызвать Claude API с промптом
7. Распарсить JSON-ответ
8. Записать прогнозы через `upsert_prediction()`
9. При любой ошибке — отправить алерт администратору

### `bot/db.py` (2 новые функции)

- `get_group_standings()` — текущее положение команд в группах: очки, голы забитые/пропущенные, результаты матчей
- `get_ai_participant()` — получить запись участника с name = 'Лёха AI'

### `vercel.json`

Добавить маршрут и cron:

```json
{ "path": "/api/cron_ai_predict", "schedule": "0 12 * * *" }
```

### `requirements.txt`

Добавить: `anthropic>=0.28.0`

## Промпт Лёхи AI

**Системный промпт:**
> "Ты Лёха AI — участник конкурса прогнозов на ЧМ-2026. Ты умный аналитик, но с характером: иногда ставишь на нестандартный счёт или веришь в аутсайдера. Анализируй данные турнира, но не бойся рискнуть. Отвечай строго JSON-массивом без пояснений."

**Пользовательский промпт** (генерируется из контекста):
```
Сегодня игровой день. Матчи:
- match_id=42: Бразилия vs Германия
- match_id=43: Франция vs Аргентина

Текущая статистика турнира:
Группа E: Бразилия 6 очков (GF:5, GA:1), Германия 4 очка (GF:3, GA:2)...
Последние результаты: ...

Предскажи счёт каждого матча. Формат ответа:
[{"match_id": 42, "pred_home": 2, "pred_away": 1}, ...]
```

**Модель:** `claude-haiku-4-5-20251001` — достаточно для прогнозов, минимальная стоимость.

## Обработка ошибок

При любой ошибке (невалидный JSON от Claude, ошибка API, ошибка записи в БД) — бот отправляет личное сообщение администратору:

> "Лёха AI не смог поставить сегодня [дата]: [описание ошибки]. Прогнозы не записаны."

Администратор может вручную обратиться за фиксом. Прогнозы в этот день не записываются.

## Переменные окружения

| Переменная | Описание |
|---|---|
| `ANTHROPIC_API_KEY` | API-ключ Anthropic |
| `ADMIN_TELEGRAM_ID` | chat_id администратора для алертов (узнать через @userinfobot) |

Существующие переменные (`DB_URL`, `BOT_TOKEN`, `CRON_SECRET`) используются без изменений.

## Идемпотентность

- Cron запускается ежедневно, но делает ранний выход если нет открытого игрового дня
- Перед вызовом Claude проверяет наличие существующих прогнозов Лёхи AI
- `upsert_prediction()` использует `ON CONFLICT DO UPDATE` — повторный запуск безопасен
